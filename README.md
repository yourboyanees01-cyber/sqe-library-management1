\# SQE Library Management System



\## Project Description

This project is a Library Management System developed as part of the 

Software Quality Engineering (SQE) course. The system is designed to 

manage core library operations, including book management, member 

management, and book search functionality.



The goal of this project is to apply software quality engineering 

principles — including proper version control, issue tracking, testing 

practices, and documentation — throughout the software development 

lifecycle using a professional GitHub-based workflow.



\## Key Features (Planned)

\- \*\*Book Management\*\*: Add, update, delete, and view books in the library catalog.

\- \*\*Member Management\*\*: Register and manage library members.

\- \*\*Book Search\*\*: Search for books by title, author, or category.



\## Project Structure

\- `src/` — Application source code

\- `tests/` — Test cases and automated tests

\- `docs/` — Project documentation

\- `screenshots/` — Evidence of testing and development activities

\- `.github/workflows/` — CI/CD workflow configurations
